# Changelog

All material changes to MeanMug-Agent behavior, prompts, schema, or
config. Reverse-chronological. Each entry: date (UTC), one-line

## 2026-05-21
- `ef9615c` — GLM-5.1 optimization pass. (1) `SYSTEM_PROMPT.md` now marks a GLM-facing directive with `<!-- glm:directive:begin/end -->`; only that region is sent to the model. Cuts the per-call system prompt from ~1500 → ~535 tokens (saves ~1000 tokens per call). (2) `GlmClient` gains an in-memory response cache keyed on `sha256(system+user)`, TTL 1h, FIFO eviction at 1000 entries — repeat `/osint` or `/pivot` on the same indicator within an hour is free. (3) `GlmResult` now carries `usage=(prompt_tokens, completion_tokens)` parsed from the response, plus a `cached: bool` flag so cached returns don't double-count tokens. (4) `audits` table gains `reasoning`, `prompt_tokens`, `completion_tokens` columns via additive migration; record_audit accepts them. (5) `/health` reports 24h prompt+completion totals and live cache size. (6) Embeds now colour by `**Threat Level**` (CRITICAL=red, HIGH=amber, MEDIUM=yellow, LOW=green, UNKNOWN=grey). (7) Embed footer surfaces `123+45 tok`, `cache hit`, and `🧠 NNNc reasoning` when present. (8) Chunker prefers `\n**` section boundaries so the 5-section report structure survives pagination. Test count 59 → 77.
- `067b411` — Catch real bugs and gaps: `/investigate` now resolves the case BEFORE the GLM call so an invalid case name never burns tokens; `subject` is capped to fit the embed title's 256-char limit; new test_real_cog_loading test wires every cog through actual discord.py `Bot.add_cog()` and asserts the tree exposes all 15 expected commands (catches `app_commands.Group` binding regressions); new test_more_paths covers cooldown-adjacent edge cases — long-analysis pagination, /case list with status filter, /backup with target and non-essential rejection, watchlist case-insensitive dedupe, /health DB-fail rendering. Test count 48 → 59.
